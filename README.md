# 看清论证 · Reasoned Lens

版本：v1.0.0。社交平台正文与评论的论证分析 Skill。

先看对方说了什么、凭什么这样说，再决定值得问什么。它帮助拆解事实、推断、价值立场与证据，给围观者留下能核对的线索，也帮助想评论的人提出有依据的反问。

适用于微博、小红书、抖音、B站、公众号、知乎、X、Reddit 等平台提供的文字、字幕、截图与评论。平台名称表示可分析这些材料，不表示内置了平台接口、可以自动抓取全部评论或访问登录内容。

## 一分钟看懂

以下内容为虚构示例。

正文 P1：“采访的 10 位成功创业者都每天早起，所以早起的人一定会创业成功。”

评论 C1：“那么多成功人士都这么做，质疑的人就是懒。”

| 先看哪一步 | 可以得出什么 |
| --- | --- |
| 正文提供的材料 | 选中的 10 位成功者都早起；真实性尚未外部核查 |
| 正文想推出的结论 | 所有早起的人都会创业成功 |
| 推理缺口 | 只观察成功者，没有早起但失败者、其他成功者或比较组；不能从该样本推出“所有人一定成功” |
| 评论增加了什么 | 没有增加数据；把对推理的质疑换成了对质疑者的评价 |
| 能改变判断的补充 | 更完整的样本、比较方式，以及是否仅主张“可能有帮助” |

可以这样问正文发布者：

> 这 10 位都是从成功者中选出来的。是否也统计了早起但创业失败的人？仅凭这组样本，怎样支持“早起的人一定成功”？

可以这样回应 C1：

> 质疑的是样本能否支持结论。评价质疑者是否勤奋，能补上哪些缺少的数据？

这些问题质疑推理，没有断言早起无用，也没有指控发布者造假。

## 能帮你做什么

- 拆分正文中的主张、依据、隐含前提与适用范围。
- 分清事实核查和论证检查，显示哪些事实尚未核实。
- 逐条审读支持、反对与纠正评论，保留回复关系。
- 检查抽样、因果、统计口径、概念替换和标准是否一致。
- 为关键缺口拟出温和或更直接的提问，说明什么回答会改变判断。
- 对合理论证明确认可，保留未知，避免把“我不喜欢”变成“它有漏洞”。

## 下载与安装

[Codex 安装包](dist/reasoned-lens-codex-1.0.0.zip) · [WorkBuddy 安装包](dist/reasoned-lens-workbuddy-1.0.0.zip) · [校验值](dist/SHA256SUMS) · [安装说明](docs/install.md)

安装后可以这样开始：

```text
请使用 reasoned-lens（看清论证）分析以下正文及评论。
先准确复述主张，分开事实、推断与立场。
指出会影响结论的推理缺口，并拟出两条有依据、可回答的反问。
不要把尚未外部核查的内容说成事实，不要替我发布。

正文 P1：……
评论 C1，回复 P1：……
评论 C2，回复 C1：……
材料范围：完整正文 / 摘录 / 截图；评论为我选择的几条。
```

只想理解、不想评论时，直接说“只分析，不写评论”。没有可访问链接时可以粘贴脱敏文字，使用 [输入模板](references/input.md)。Skill 依赖宿主模型；联网核查需要宿主提供相应工具。

## 共同改进

欢迎贡献脱敏或虚构案例、修正出处和反馈“原文没这么说”“问题预设了结论”“评论归属错了”等具体错误。先看 [贡献说明](CONTRIBUTING.md)。公开 Issues 不接收私密聊天、个人账号档案或动员围攻。

本项目不为发布者打人格分数、不推断幕后动机、不提供刷评功能。评论草稿由你选择是否使用；你也可以选择补充材料、修改自己的判断或不参与争论。

## 维护与许可

维护者可用 Python 3.9+ 重新打包与检查，普通使用者不需要运行脚本：

```sh
python3 scripts/build.py
python3 scripts/verify.py
```

项目采用 [MIT](LICENSE)。仅包含指令和参考资料的安装包不附带模型、服务器或社交平台连接器。

English: A portable skill for auditing arguments in social posts and comment threads, separating evidence from inference and drafting answerable, evidence-linked questions.
