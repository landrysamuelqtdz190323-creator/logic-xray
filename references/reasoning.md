# 推理检查：找到从依据到结论的缺口

这些是审读工具，不是看到关键词就能触发的标签。先复述论证，再判断缺口是否影响核心结论。若只能提出一种可能性，就写“需要检查”，不能写成已经发现造假。

| 检查方向 | 真正要看什么 | 可回答的问题 |
| --- | --- | --- |
| 抽样与以偏概全 | 样本从哪里来、排除了谁、结论扩大到哪些人 | 这组样本怎样覆盖你要概括的人群？ |
| 因果与替代解释 | 时间先后、比较条件、共同原因是否被排除 | 除了这个因素，还有哪些变化可能解释结果？ |
| 分母与统计口径 | 百分比基数、绝对值、期间、对象是否一致 | 这里的百分比以什么为分母，两组口径相同吗？ |
| 来源与权威范围 | 引用者是否确实说过、专业范围是否相关 | 可以给出原始出处，并说明哪一段支持这个结论吗？ |
| 概念变化 | 同一个词是否从一个定义换成了另一个 | 这里两次使用的“成功”分别指什么？ |
| 非此即彼 | 两个选项是否穷尽所有可行情况 | 除这两种选择，还有没有与你的目标相容的方案？ |
| 稻草人与引用偏移 | 回应的是实际观点，还是更极端的改写 | 对方哪句话表达了你回应的这个主张？ |
| 标准是否一致 | 相同相关条件下，是否更换证据或评价要求 | 对相同情况，这个标准也同样适用吗？ |
| 举证责任 | 提出事实主张的人是否提供了足够依据 | 除了别人尚未否定，有什么支持这一说法的证据？ |
| 话题转移 | 别的事件是否真的改变当前问题的判断 | 这个例子具体改变了当前哪项依据或结论？ |
| 人身评价代替论证 | 个人身份、动机、能力评价能否补上证据 | 这项评价如何回答原先提出的证据问题？ |
| 循环与不可反驳 | 结论是否被当作自己的依据，反例是否永远被排除 | 什么可观察的情况会让你修正这个判断？ |

## 不要把标签当证明

“大家都这样做”可以解释一个惯例，不单独证明它正确。“专家说”可以是相关线索，也需要原始出处和适用范围。指出利益关系可以是合理的证据审查，但不等于反驳其数据。

类比并非天然有错：关键是类比所依赖的相似点是否与结论有关。两项措施的价值比较可能并没有唯一答案；应澄清原则、目标与代价，而不是把价值分歧标成事实错误。

## 把缺口写完整

有用的判断至少包含：原文位置、实际推理、缺失的连接、影响范围、可能的修补方式。例如：“P1 从 10 位成功者的共同习惯，推到所有人的成功保证；样本未覆盖失败者，因此不支持‘一定’，但不能据此否定这个习惯的任何作用。”

遇到看似矛盾的表达，先检查对象、时间与条件是否变化。条件不同可能解释差异；只有相关条件相同且标准不一致时，才有充分理由追问双重标准。
