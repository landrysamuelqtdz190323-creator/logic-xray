# 证据与事实核查

论证检查回答“这些依据是否足以推出这个结论”；事实核查回答“这项可核查说法在指定时间和范围内是否得到证据支持”。两者分别报告，不能用逻辑检查结果替代外部核查。

## 核查记录

针对关键主张保存一个简短证据记录：

| 字段 | 内容 |
| --- | --- |
| 主张与编号 | 明确对象、时间、范围的原话或转述 |
| 当前材料 | 原文给了什么；用户额外提供了什么 |
| 本次读取 | 实际阅读的原始页面或文件、发布日期、访问日期 |
| 支持范围 | 来源支持哪一部分，没有支持哪一部分 |
| 独立性 | 原始调查 / 独立来源 / 引用同一出处的转载 |
| 状态 | 有支持 / 有反证 / 证据混合 / 未核实 |
| 下一步 | 需要什么材料，或当前可以保留怎样的较窄结论 |

“有支持”仅表示所列来源支持指定范围，不是绝对真实认证。来源冲突时说明对象、期间、方法差异；“没有找到”不自动等于不存在。“未核实”也不自动等于可疑或错误。

## 核查重点

有原始资料就回到原始资料：原始报告、数据表、完整讲话、论文和官方记录。网页可编辑、报道可更新，保留时间与版本。搜索结果摘要可以帮助定位，不能代替实际阅读。

引用研究时核对作者、研究对象、测量方式、限制与结论强度。一个论文标题、截取的图或“研究表明”不足以把观察性关联改写成个人保证或普遍因果。

核对数字的分母、绝对量、样本大小、币种或单位、比较期。相对增长可能来自很小的基数；百分比变化和百分点变化分开表述。没有原始数字时不能补算看起来漂亮的结果。

跨平台转述、截图与媒体转载可能指向同一个起源。应识别共同来源，不能把传播次数当作独立验证次数。付费推广或其他利益关系是披露线索，不单独构成事实反证。

## 工具不可用时

只做材料内的论证检查，明确列出尚未核查的事实和可补充的资料。不能伪造来源、声称读过打不开的链接，或把宿主联网能力写成 Skill 自带的功能。

涉及医疗、法律或金融的具体说法，应核对对应的原始专业资料与适用地区，不依赖社交平台转述给个人作决定。公开讨论也可以只保留“需要原始出处”的问题。
