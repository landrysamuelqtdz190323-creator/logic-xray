# 提问：直接指出连接处，让对方有机会回答

好的反问同时满足三点：准确对应原文、指向影响结论的缺口、允许提供证据后修正判断。尖锐不需要侮辱；质疑不需要先认定对方撒谎。

## 可复用的写法

| 缺口 | 温和表达 | 更直接的表达 |
| --- | --- | --- |
| 缺原始出处 | 可以补充原始资料和相关段落吗？ | 这个结论具体依据哪份原始资料，而不只是转述？ |
| 从部分推到全部 | 这组样本适用于哪些人，哪些人暂时不能涵盖？ | 从这几位受访者，怎样推出你说的“所有人”？ |
| 把关联说成因果 | 有哪些比较材料能区分这个因素与其他变化？ | 除了同时出现，你提供了什么依据说明是它造成的？ |
| 口径变化 | 两组数据的对象和期间是否一致？ | 如果分母和期间不同，这个比较怎样成立？ |
| 双重标准待核 | 两种情况的相关条件相同吗？ | 在相同条件下，这个证据标准是否也适用于另一方？ |
| 把批评换成人身评价 | 能回到具体的证据问题吗？ | 评价提问者的身份，如何补上结论需要的依据？ |
| 结论不允许反例 | 哪种观察会使你修改这个说法？ | 如果任何反例都被排除，这个判断怎样接受检验？ |

这些是表达模板，不是对任意帖子的现成判词。只使用材料中确实出现的词和适用的条件。

## 发布前的自检

1. 找得到问题对应的原文位置吗？如找不到，改为开放澄清，不指控漏洞。
2. 有没有把“可能”写成“一定”，或把一个评论者的发言归给作者？
3. 问题里是否夹带了未经核实的事实、动机或罪名？删掉这些前提。
4. 对方提供什么具体回答后，你会改变判断？若没有任何答案可接受，这更像表态或讽刺。
5. 相同标准是否也用于你赞同的内容和自己的草稿？

对于复杂材料，一段评论集中处理最重要的一个缺口通常比堆十个谬误名称更易理解。用户要求多问时可以给备选，说明各自针对的主张；不要自动批量刷评论。

## 不预设有错

坏问题：“你故意隐藏失败者，是想骗谁？”

可核对的问题：“这组样本是否包含失败者？如果不包含，它怎样支持关于所有创业者的结论？”

坏问题：“你是不是根本不懂统计？”

可核对的问题：“这里说增长了 100%，原来的数量是多少，比较的时间区间是什么？”

如果原文已经提供这些信息，就不要再用问题假装对方没提供。分析结果可以是认可、补充范围、修改自己的质疑，或不评论。
